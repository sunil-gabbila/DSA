# DSA - Java Practice

This repository collects Java solutions and exercises for data structures and algorithms. Topics are organized into focused directories for independent study and interview practice.

## Practice workflow

1. Understand the problem's inputs, outputs, and constraints.
2. Start with a simple correct approach, then optimize it.
3. Test normal and edge cases.
4. Review time and space complexity and explain the approach in your own words.

## Requirements

Install a JDK and verify `java -version` and `javac -version`. For a standalone solution, run `javac FileName.java` and then `java ClassName` from its directory. Check each exercise for its input format.
