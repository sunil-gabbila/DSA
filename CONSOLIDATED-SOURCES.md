# Consolidated topic sources

Java practice solutions are grouped under this directory:

- `03-HashMap-HashSet/hashmap/` — mapping, anagram, character, and HashMap problems.
- `04-Freaquency-Problems/frequency/` — counting, duplicate, and frequency problems.
- `05-PrefixSum-RunningSum/prefixsum/` — prefix-sum and subarray-sum solutions.
- `05-PrefixSum-RunningSum/runningsum/` — running-sum and range-sum solutions.

Each source is a standalone exercise with its own `main` method. Compile an individual file with `javac FileName.java` from its directory. These files are consolidated copies; the original repositories are unchanged.
